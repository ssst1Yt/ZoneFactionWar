ЗОНА: Война группировок — Android-проект оболочки приложения
=========================================================

Внутри находится Android Studio / Gradle проект. Игра открывается внутри WebView,
поэтому её интерфейс адаптирован под экран телефона.

Как собрать APK:
1. Установите Android Studio на компьютер.
2. Откройте папку ZoneFactionWar в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Выберите Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Важно:
- Это исходный проект, не готовый подписанный APK.
- Сборка требует Android Studio, JDK и скачивания Android Gradle Plugin/SDK.
- В игре пока нет сетевого мультиплеера; война группировок работает локально.
- Название и контент — фанатский прототип, не официальный продукт S.T.A.L.K.E.R. или War Groups.
